OLI Mobile Valet — Website Asset Pack

Files included:

- 06_water_splash_line_dark_transparent.png and 06_water_splash_line_light_transparent.png: transparent overlay versions for the hero divider/wash reveal.

Important quality note:
These files were separated and upscaled from the generated contact-sheet output, because the image generator returned one combined sheet rather than true individual image files. They are suitable for concept build/prototyping and may be usable on web with responsive sizing/compression. For final production, regenerate the main hero/front car images individually at native high resolution for cleaner detail.

Recommended usage:
- Hero: use 02_hero_clean_front.jpg and 03_hero_dirty_front.jpg layered with CSS mask/reveal. Use 01_hero_before_after_front.jpg as fallback static image.
- Transformation section: use 04_side_profile_transformation.jpg.
- Overlay: animate 05_paint_reflection_overlay.jpg very subtly with mix-blend-mode: screen or overlay.
- Divider/wash effect: use 06_water_splash_line_light_transparent.png on dark/hero areas.
- Detail cards: use 07_interior_detail.jpg and 08_wheel_detail.jpg.
- Icons: use SVG files inline or as external images, with CSS color via currentColor.
